# 🟡 مرصاد الذهب (Gold Radar)

منظومة آلية ومفتوحة المصدر لمراقبة أسعار الذهب في السوق المصري لحظة بلحظة. يقوم المشروع برصد سعر جرام الذهب عيار 24 (سعر البيع)، وحساب السعر العادل بناءً على سعر الأونصة العالمية وسعر صرف الدولار والوزن الترويسي الرسمي، وتحديد الفجوة السعرية وحالة السوق. وعند تحرك السعر المحلي بنسبة 0.25% أو أكثر مقارنة بآخر تنبيه، يُرسل النظام إشعاراً فورياً ومختصراً عبر تيليجرام. يعمل المشروع تلقائياً وبشكل مجاني تماماً كل 5 دقائق عبر GitHub Actions، دون الحاجة لتشغيل جهاز كمبيوتر أو استئجار خادم خاص.

---

## ⚙️ كيف يعمل المشروع؟

1. **جلب الأسعار لحظياً من 3 مصادر رسمية ومفتوحة:**
   - **سعر أونصة الذهب عالمياً (بالدولار):** من واجهة Gold-API الرسمية.
   - **سعر صرف الدولار مقابل الجنيه المصري:** من واجهة fawazahmed0 currency-api مع وجود مصدر احتياطي تلقائي (ExchangeRate-API).
   - **أسعار الذهب المحلية في مصر:** من موقع «آي صاغة» لعيارات (24، 21، 18) والجنيه الذهب (شراء وبيع).

2. **الحسابات والمؤشرات:**
   - **السعر العادل لعيار 24:** $\text{Ounce USD} \times \text{USD/EGP} \div 31.1035$.
   - **الفجوة السعرية:** الفرق بين السعر المحلي والسعر العادل ونسبتها المئوية.
   - **حالة السوق:** (أعلى / أقل / متوازن) وفق نسبة الفجوة.
   - **سعر عيار 14:** يُشتق حسابياً بدقة: $\text{Price 24k} \times \frac{14}{24}$ ويُميز بـ *(محسوب)* لعدم تداوله بأسعار شاشات منتظمة.

3. **آلية التنبيه الذكية ومكافحة الأخطاء:**
   - إرسال تنبيه في الدورة الأولى لبدء المتابعة.
   - إرسال تنبيه جديد للعملاء فقط عند تحرك السعر بنسبة $\ge 0.25\%$ صعوداً أو هبوطاً مقارنة بآخر تنبيه.
   - كشف القفزات المشبوهة المفاجئة (أكبر من 5%) وتجميد التنبيه للعملاء حتى التأكد من ثبات السعر خلال دورات متتالية.

4. **التخزين في جداول جوجل (Google Sheets):**
   - **ورقة «الحالة»:** لحفظ سعر آخر تنبيه، آخر سعر تم رصده، عداد القفزات المشبوهة، وبيانات صحة النظام.
   - **ورقة «التاريخ»:** تسجيل صف مفصل لكل دورة فحص يوثق الوقت والأسعار والفجوة والإجراء المتخذ.

5. **رسائل خاصة للمشرف ونبض الحياة اليومي (Owner Health & Heartbeat):**
   - **تنبيه الأعطال:** عند فشل 3 دورات متتالية، يُرسل تنبيه خاص للمشرف فقط مع سبب العطل الآمن، ولا يُكرر التنبيه إلا بعد مرور 6 ساعات.
   - **إشعار التعافي:** عند عودة النظام للعمل بنجاح بعد انقطاع، يُرسل فوراً: `✅ مرصاد الذهب رجع يشتغل`.
   - **تنبيه القفزات المشبوهة:** عند رصد قفزة مفاجئة، يُرسل للمشرف فقط إشعاراً يفيد بتجميد التنبيه عن العملاء.
   - **نبض الحياة اليومي (Heartbeat):** رسالة يومية تؤكد سلامة النظام تُرسل للمشرف في تمام أو بعد الساعة 9:00 صباحاً بتوقيت القاهرة متضمنة أحدث الأسعار وحالة السوق.

## 💻 التشغيل المحلي (Local Setup)

### 1. إعداد البيئة وتثبيت الحزم
يُنصح باستخدام بيئة افتراضية (Python 3.12):
```bash
# إنشاء وتفعيل البيئة الافتراضية
python -m venv .venv
source .venv/bin/activate  # على أنظمة Linux/macOS
# أو على Windows:
# .\.venv\Scripts\activate

# تثبيت الاعتماديات المحددة
pip install -r requirements.txt
```

### 2. إعداد المتغيرات السرية (.env)
أنشئ ملفاً باسم `.env` في المجلد الرئيسي للمشروع، وأضف فيه أسماء المتغيرات التالية (الملف محمي ومدرج تلقائياً في `.gitignore` لمنع رفعه):
```env
TELEGRAM_BOT_TOKEN=ضع_توكن_البوت_هنا
TELEGRAM_CHAT_ID=ضع_معرف_المحادثة_أو_القناة_هنا
GOOGLE_SERVICE_ACCOUNT_JSON=ضع_محتوى_ملف_الحساب_كاملا_على_سطر_واحد
GOOGLE_SHEET_ID=ضع_معرف_جدول_جوجل_هنا
TELEGRAM_ADMIN_CHAT_ID=اختياري_معرف_محادثة_المشرف_الخاصة
```

### 3. أوامر التشغيل
- **تشغيل اختبارات الوحدة المعزولة بالكامل:**
  ```bash
  pytest -v
  ```
- **تشغيل تجريبي للمعاينة (--dry-run):**
  يجلب الأسعار الحقيقية لحظياً ويُجري الحسابات ويعرض نص الرسالة في الطرفية دون الاتصال بتيليجرام أو تعديل جداول جوجل:
  ```bash
  python tools/run_local.py --dry-run
  ```
- **التشغيل الفعلي الكامل محلياً:**
  ```bash
  python tools/run_local.py
  ```

## 🚀 الإعداد على GitHub Actions

يعمل المشروع على GitHub Actions تلقائياً وفق جدول زمني كل 5 دقائق (`cron: "*/5 * * * *"`).

### 1. إضافة الأسرار (Repository Secrets)
ادخل إلى مستودعك على GitHub ثم توجه إلى:
`Settings` ➔ `Secrets and variables` ➔ `Actions` ➔ اضغط على `New repository secret`، وأضف الأسرار التالية بأسمائها المطابقة تماماً:

1. `TELEGRAM_BOT_TOKEN`: رمز التوكن الخاص بالبوت الذي أنشأته عبر `@BotFather`.
2. `TELEGRAM_CHAT_ID`: معرف المحادثة أو القناة العامة المخصصة للمتابعين.
3. `GOOGLE_SERVICE_ACCOUNT_JSON`: النص الكامل لمفتاح حساب الخدمة (JSON) الخاص بجوجل، موضوعاً بالكامل على سطر واحد.
4. `GOOGLE_SHEET_ID`: معرف الجدول الخاص بك (الموجود في رابط جدول جوجل بين `/d/` و `/edit`).
5. `TELEGRAM_ADMIN_CHAT_ID` *(اختياري)*: معرف محادثتك الشخصية على تيليجرام إذا أردت استلام تنبيهات الأعطال والنبض اليومي بشكل منفصل عن قناة المتابعين. (إذا لم يُحدد، ستصل رسائل الإدارة إلى `TELEGRAM_CHAT_ID`).

### 2. تشغيل سير العمل يدوياً
يمكنك تشغيل الدورة في أي وقت دون انتظار موعد الـ Cron:
- توجه إلى تبويب **Actions** في مستودعك.
- اختر سير العمل **Gold Radar** من القائمة اليسرى.
- اضغط على زر **Run workflow** ثم اختر الفرع `main`.

## 🛠️ الصيانة والإدارة (Maintenance)

- **قاعدة الـ 60 يوماً في المستودعات العامة (GitHub Inactivity Rule):**
  يقوم GitHub بإيقاف سير العمل المجدول تلقائياً في المستودعات العامة إذا مر **60 يوماً متتالية** دون أي نشاط داخل المستودع.
  - *الحل البسيط:* قم بعمل تعديل بسيط (Commit) كل 45 يوماً تقريباً، أو قم بتشغيل سير العمل يدوياً مرة كل شهر من تبويب Actions لتنشيط المؤقت.
  - في حال توقف الـ Workflow، يمكنك إعادة تفعيله بضغطة زر واحدة من تبويب Actions باختيار **Enable workflow**.
- **تعديل الثوابت ونسب التنبيه:**
  يمكن ضبط أي قيمة بسهولة عبر تعديل ملف `src/gold_radar/config.py`:
  - `ALERT_THRESHOLD_PCT`: نسبة حركة السعر المطلوبة لإرسال تنبيه (افتراضياً 0.25%).
  - `ALERT_AFTER_FAILURES`: عدد مرات الفشل المتتالية قبل إرسال إنذار عطل (افتراضياً 3).
  - `HEARTBEAT_HOUR_LOCAL`: توقيت إرسال نبض الحياة اليومي (افتراضياً 9:00 صباحاً بتوقيت القاهرة).
- **تدوير توكن تيليجرام (Rotate Telegram Token):**
  في حال رغبتك بتغيير التوكن، ادخل للبوت `@BotFather` في تيليجرام، أرسل الأمر `/revoke`، ثم اختر البوت الخاص بك لإنشاء توكن جديد فوراً، وقم بتحديث قيمته في GitHub Secrets وملف `.env` المحلي.
- **تدوير مفتاح Google Service Account:**
  ادخل إلى منصة Google Cloud Console ➔ توجه إلى `IAM & Admin` ➔ `Service Accounts` ➔ اختر الحساب ➔ تبويب `Keys` ➔ أنشئ مفتاحاً جديداً بصيغة JSON، ثم احذف المفتاح القديم، وقم بتحديث السطر في GitHub Secrets.
- **ماذا لو تعطل أحد المصادر؟**
  - في حال تعطل مصدر الدولار الأساسي، يتحول النظام تلقائياً إلى المصدر البديل (ExchangeRate-API).
  - في حال تغيير تصميم صفحة أسعار آي صاغة، فإن دالة الاستخراج مجمعة ومنفصلة داخل `src/gold_radar/sources/isagha.py` لتسهيل تعديلها دون المساس بباقي المنظومة.
